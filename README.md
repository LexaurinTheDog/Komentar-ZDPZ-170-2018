# Komentář k zákonu č. 170/2018 Sb., o distribuci pojištění a zajištění

Otevřený komentář k zákonu o distribuci pojištění a zajištění — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; samostatný zprostředkovatel, vázaný zástupce a doplňkový pojišťovací zprostředkovatel, registr ČNB, odborná způsobilost, pravidla jednání a informační povinnosti, investiční životní pojištění, dohled a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2018-00170_2025-07-01`.
